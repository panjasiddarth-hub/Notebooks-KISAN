Project Title : Kisan AI Sahayak
AI-Powered Personalized Farming Assistant
Includes agents for different assistance for farmer
The proposed system should:
•	Recommend the best crop(s) based on land characteristics. 
•	Predict expected yield and profitability. 
•	Recommend fertilizer schedules. 
•	Estimate irrigation requirements. 
•	Suggest crop rotation strategies. 
•	Detect climate risks. 
•	Recommend pest and disease prevention. 
•	Forecast market prices. 
•	Explain every recommendation in simple language.
